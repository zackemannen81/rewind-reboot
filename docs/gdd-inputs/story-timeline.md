# Story timeline

Derived brief. Compiled from `docs/design/the-macro-loop.md` and
`docs/design/echo.md`. Do not hand-edit.

**This file has two layers and they are not the same kind of thing.** Layer A
is what the player experiences, in order. Layer B is what the fiction claims
happened. Only Layer A is world state. **Never cite Layer B as established
fact in a manuscript** — the macro cycle is fiction, nothing simulates it, and
a writer who treats it as retrievable history will have the game explain
itself.

## Layer A — the player's order

This is the only chronology the game can be built from.

| # | Chapter | Space | Ends when |
| --- | --- | --- | --- |
| 1 | Apartment 4C and the building | 4C, fourth-floor hall, lift, stairwell, ground hall, courtyard | The player commits `courtyard_gate_open` and leaves for the Transit Hub |
| 2 | Conduit | Transit Hub and the tunnels below the city | Designed in `chapter-2-authored.md` |
| 3 | unwritten | | |
| 4 | unwritten | | |
| 5 | unwritten | | Final event, then the cycle restarts at Chapter 1 |

Inside a chapter, time is the local loop: it starts, it runs on a clock that
never varies, and it ends by contract failure, death or first Anchor commit.
Loops are cheap. Repetition is the verb.

## Layer B — what the fiction claims

Unprovable inside the game, and that is deliberate. Nothing here may be stated
outright by any character, message or Echo. It is only ever implied by
evidence the player can test.

- The Returner has made this journey before. Many times.
- Chapter 1 is not the start of the journey; it is the point at which he begins
  to remember it.
- Some things in Chapter 1 were prepared by someone. Later: by him, in an
  earlier cycle.
- The final event of the cycle causes the reset that puts him back in 4C.
- Each cycle preserves something the last could not — an observation, an Echo,
  a change in who is watching the system.

## How the two layers meet

Only through **Echo** and **planted details**, and both are authored staging.

An Echo shows a Layer B event inside a Layer A space. That is the only bridge.
It never changes Layer A world state, which is why an Echo can pull a fuse that
is still sitting in the panel: the contradiction is the evidence.

A planted detail is a Layer A object that only makes sense under Layer B. It is
placed long before it means anything and never explained when it is placed.

## Reveal order

Layer B is revealed in seven stages, one ladder for the whole game, each rung
climbed once. The stages, their budget per chapter, and the rule that an Echo
is never a hint all live in the Echo document. Follow that budget. Do not
escalate past the stage this chapter is allocated, however tempting the scene.
