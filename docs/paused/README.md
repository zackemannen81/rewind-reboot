# Paused Tasks

Discoverability: index. Every member of this directory is listed below.
Member state: required. Every member declares a `Status:` line under its title.

Frozen parent tasks waiting on a named prerequisite, child task or external
condition. A paused task keeps its identity, goal and definition of done, and is
restored to `docs/CURRENT_TASK.md` unchanged when its resume condition is met.

This is not a general backlog. Work that was never chartered belongs in
`docs/backlog/`.

No tasks are paused.
