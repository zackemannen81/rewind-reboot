# Backlog Proposals

Discoverability: index. Every member of this directory is listed below.
Member state: required. Every member declares a `Status:` line under its title.

Non-activated proposals discovered outside the active charter but inside the
project's scope. A proposal records discovery context, proposed outcome, why it
is outside the active task, dependencies and suggested verification.

A proposal's filename is a permanent identifier, not a status field. Resolving
one updates its `Status:` line and its row below; it is never renamed or moved,
because journal entries and archived tasks cite proposals by path and cannot be
edited to follow a rename.

Assign a `REW-NNNN` identity only when a proposal is explicitly activated.
