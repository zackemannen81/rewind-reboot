# Multi-Agent Waves

Discoverability: naming convention
Member state: required

Wave plans are named `{TASK-ID}_task-slug.md`. Each belongs to one operator
task and records the frozen worker allocation, ownership matrix, global locks,
merge order, combined gates and crash-recovery surface for that delegated
wave.

The repository remains the authority. MCP process state and worker output do
not replace task charters, commits, review or named verification evidence.
