# RE:WIND Chapter 1 audio sources

Provenance: generated by REW-0033 on 2026-08-26. The four radio words use the
offline, locally installed Windows SAPI `Microsoft Zira Desktop` voice at rate
`-2`; every other source is deterministic numpy/scipy synthesis. No downloaded
or third-party sound library material is present.

Run `python Rewind/ArtSource/Scripts/generate_chapter1_audio.py` at the
repository root to recreate the mono, 44.1 kHz, 16-bit PCM WAVs. The generator
uses fixed RNG seed `7312` and writes `generation_report.json`, whose values
are read back from the written WAVs rather than predicted from processing
parameters.

The assets are intentionally separate from their Unreal imports. Re-import with
`Rewind/ArtSource/Scripts/import_chapter1_audio.py`; it imports to
`/Game/Audio/Chapter1/` and verifies SoundWave duration and loop settings. Only
the two `_Loop` assets are looping; all digit, interaction and footstep assets
are one-shots.
