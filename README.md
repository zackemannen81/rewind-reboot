# RE:WIND

A third-person psychological sci-fi puzzle game. The world resets in
deterministic loops. The player's knowledge does not.

This repository is a cold-start reboot. An earlier Unity project exists as
read-only source material. None of it is authority here until it has been
restated in an owning document under `docs/`.

The engine is Unreal Engine 5.8, decided in
[`docs/adr/ADR-0001_engine-unreal-engine-5.md`](docs/adr/ADR-0001_engine-unreal-engine-5.md).

## Where to start

Read `AGENTS.md`, then the reading order it names. The active task is always
`docs/CURRENT_TASK.md`. What exists now is `docs/CURRENT_STATUS.md`.

## What this is not

It is not the previous Unity project. It is not a complete game. It is not
open source until a license decision says so. A `LICENSE` file with
Apache-2.0 text remains from the docs-first working model this repository
was bootstrapped from; that is provenance, not a grant for RE:WIND.

## Current phase

Bootstrap of canonical project state. No Unreal project, no design authority
and no implementation live in this tree yet. The first product proof, once
chartered, is the Five Loops Test described in `docs/PROJECT_BRIEF.md`.
